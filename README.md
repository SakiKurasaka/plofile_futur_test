# futur — Portfolio

Figmaのデザインをもとに制作した、Web制作ポートフォリオの静的サイトです。

## ファイル構成

- `index.html`：自己紹介、作品一覧、Instagram、お問い合わせエリア
- `style.css`：PC・タブレット・スマートフォン向けのスタイル
- `app.js`：メニュー、作品枠の詳細表示、相談メモ作成
- `assets/`：Figmaから書き出した元のロゴ、フレーム、アイコン

## プレビュー

ビルドやパッケージのインストールは不要です。`index.html`をブラウザーで開いて確認できます。

Python 3がある場合は、リポジトリのフォルダーで次を実行するとローカルサーバーで確認できます。

```bash
python3 -m http.server 8000
```

その後、`http://localhost:8000/`を開いてください。

## 現在の状態

- レスポンシブ表示、宝箱メニュー、作品枠の切り替えに対応しています。
- 作品画像・作品情報・Instagramの写真は未登録のため、デザイン上の空き枠を残しています。
- お問い合わせ先は未設定です。メールアイコンから相談内容のメモを作成し、コピー・テキスト保存できます。送信機能はありません。
- Instagramのリンク先は`@sakimaru72`です。
- 入力内容はサーバーへ送信・保存しません。
